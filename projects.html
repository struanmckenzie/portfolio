University Assignments

These projects are ones I developed for assignments in my computer science degree that I deem worthy of showing off what I can do.

NotChat

NotChat (play on WhatsApp) is a group project written in Java. It's a messaging client using Java gui libraries and mimics an actual messaging app. My main job was to develop the chat window and save/load chats in the pane. We used git for version control and GitHub as a way to develop it as a team.
NotChat - GitHub

Co-Creators William Chadwick, Lewis Jackson, Jack Beal

Project Nova

This program is effectively battle-ships, but you have power ups and booby-traps to deal with and has a surprisingly long play time. The creatures and traps are randomly placed, the game state can be saved and loaded from text files. I was given a brief and from there designed and developed the whole program in Java. Project Nova - GitHub

Memory Game

This was the first project I worked on as part of a team. We decided to make a memory game using a few Raspberry Pi Picos and MicroPython. It uses physical buttons, lights, and buzzers and all links together using an MQTT server. And integrates a website to show players' progress. In this project I created the lights and sound effects for any events that occurred and as part of the team I played a part in coming up with how it would actually work.
Memory Game - OneDrive

Co-Creators William Chadwick, Lewis Jackson, Jack Beal
