University Assignments

These projects are ones I developed for assignments in my computer science degree that I deem worthy of showing off what I can do.

NotChat

NotChat (play on WhatsApp) was a group project written in Java. It was a graphical messaging program where we used gui libraries in Java to create a fake messaging client. Its main goal was to demonstrate our understanding of data structures and gui in Java. You can 'send' messages and save/load chats from memory, view them in a chat pane, create new chats, etc.
NotChat - GitHub

Co-Creators William Chadwick, Lewis Jackson, Jack Beal

Project Nova

This was my final project for the Introduction to Software Development module. It's built in Java for the command line, I made it look as pretty as I could without having to make a GUI which I didn't know how to program at the time. The game itself is effectively battle-ships but you have power ups and booby-traps to deal with and has a surprisingly long play time. The creatures and traps are randomly placed, the game state can be saved and loaded from text files.
Grade: A2 (104/110)
Project Nova - GitHub

Memory Game

This was the first project I worked on as part of a team. We decided to make a memory game using a few Raspberry Pi Picos and MicroPython. It uses physical buttons, lights, and buzzers and all links together using an MQTT server. We also thought it would benefit from a website that updates with players' progress.
Grade: A1
Memory Game - OneDrive

Co-Creators William Chadwick, Lewis Jackson, Jack Beal

Emergency Dispatch System

This project was for the Introduction to Data Structures and Algorithms module. It's a program where the user can log different "incidents" in an area/district.
Grade: A2 (111.5/125)
EmergencyDispatchSystem - GitHub
